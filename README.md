# NG Plumbing & Heating website

The website for NG Plumbing & Heating, served by GitHub Pages at https://ngplumbingandheating.co.uk/.

- `index.html`: the whole site (one page, no build step).
- `logo.png`: logo, favicon and the image shown when the link is shared.
- `CNAME`: tells GitHub Pages to use ngplumbingandheating.co.uk.
- `robots.txt` and `sitemap.xml`: help Google find the page.

To change a phone number, email or service, edit `index.html` and merge into `main`; the site updates within a minute or two.
